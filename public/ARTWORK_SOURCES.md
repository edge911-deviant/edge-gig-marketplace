# EDGE public-site artwork sources

The hero uses real documentary photographs downloaded for local hosting. The
files are served from the repository rather than hotlinked, so the page remains
stable and does not disclose visitor traffic to an image board.

All four source pages identify the photographs as free to use under the
[Unsplash License](https://unsplash.com/license). Source details were checked on
2026-10-02.
